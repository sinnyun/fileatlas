# 画布菜单中文翻译验证（2026-10-26）

## 实现与结果

画布引擎不直接依赖本地化插件；FileAtlas 画布宿主把 UI Bridge 的 `i18n::tr` 安装为引擎的界面翻译回调。工具提示、工具组、格式菜单、字体菜单、右键上下文菜单、模板/颜色提示及页面/图片卡片标记通过既有 Fluent 目录翻译。场景中的文本、画板名称、文件名和资源标题保持用户数据原样。

- 中文目录新增 56 条画布界面消息，英文目录提供对应回退文案；复用目录中已有的通用词条，不覆盖既有 ID。
- 同进程 FileAtlas MCP 使用隔离 profile `.local/validation/profiles/canvas-i18n-menu-2026-10-26`，语言为 `zh-CN`。脚本创建画板、放入隔离图片并通过 `control_ui` 真实右键打开选中对象菜单。菜单中的“置于顶层、上移一层、下移一层、置于底层、复制、剪切、粘贴、保存为模板”均以中文显示。
- 截图是同进程 `screenshot_window` 返回并人工检查的结果：[右键菜单中文截图](../../../.local/validation/artifacts/2026-10-26-canvas-i18n/context-menu-zh.png)。截图保留了该隔离 profile 默认启用的组件审查描边；此描边仅用于调试，不属于画布外观。
- 可复现命令：`cargo +1.97.1 build --locked --offline --bin fileatlas-shell -j 2`；`node scripts/fileatlas-mcp-debug.cjs --exe target/debug/fileatlas-shell.exe --profile .local/validation/profiles/canvas-i18n-menu-2026-10-26 --plugins whiteboard --access-level full --scenario scripts/validate-canvas-i18n-menu.cjs`。
- 受影响 crate locked check 通过，i18n 测试 4/4 通过；主题、刷新和 feature-ledger 守卫通过。架构守卫输出了当前未提交 Eagle Links 功能带来的新边和 baseline 提示；该提示不由本次本地化改动引入。

## 覆盖边界

本次实测了画布窗口和右键菜单中文。字体/颜色/模板弹层中的所有文字、英语切换后画布全状态、悬停工具提示及窄窗口尚未逐项运行验证。目录测试确认中英文 Fluent 消息可解析；运行截图证明右键菜单实际走通中文翻译回调。
