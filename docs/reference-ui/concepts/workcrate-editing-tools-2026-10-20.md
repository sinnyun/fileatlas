# WorkCrate 编辑扩展清单

使用内置 imagegen 生成 workcrate-editing-tools-2026-10-20.png；提示覆盖多行文本、
右侧预设下拉、插件字段设置和页面批量选择。原三层结构和固定 A3 简化语义继续有效。
生成图中的多余缩放/旋转、示例标签排布和“微软黑”误字不作为新功能；实际固定微软雅黑。

- 编辑页保留左 180 页面栏、中部 A3、右 310 检查器。工具栏增加添加文本。
- 纸内信息条保持；下方图片和多个文本独立排版，文本可选择/移动/调整框尺寸，显示四角手柄。
- 文本检查器提供多行内容、微软雅黑、字号 pt、原生颜色选择、宽高 pt、保存/删除。
  文本改框宽度重新换行，不拉伸字形。正文与 PNG/PDF 使用同一 DesignCraft 文本框。
- 页面内容每行保持标签、手动填写值、相邻预设下拉的横向排列；全局名称仍可继承/局部修改。
- 设置中心复用 SettingsPage 通用表单。每字段一组，可添加多个预设输入、删除预设、保存，
  添加/删除自定义字段；现有页面字段值不随预设修改而被覆盖。
- 页面管理三列卡片，底部单行优先：多选、全选、取消全选、取消多选、选中数、导出；
  小宽度可换行，页脚不裁切。多选模式点缩略图切换选中，编辑按钮保持进入编辑。
- 默认/选中/禁用/聚焦/下拉/错误采用原生主题；正文图片与用户文本色是内容数据。
- 替换/更新均按 max(frame_w/new_w,frame_h/new_h) 等比居中铺满旧框，裁剪框/坐标不变。

存储：页面新增 serde-default texts 记录，真实故事/字体/颜色/框几何保存在 DesignCraft
源文档中。全局字段预设采用 WorkCrate 根目录版本化 field-presets.json，复用 Projects
原子 JSON 保存/恢复工具与 Cordis 生命周期；不建独立 DB 或插件管理器。

## 2026-10-21 文本交互纠正（用户最新要求）

- 沿用图中的中央文本框和右侧字号/颜色/宽高布局，不重排三层页面。
- 新增文本立即在纸内获得输入焦点；双击已有文本在画布直接输入多行。
- 正文编辑使用同一 GPUI Kit TextareaState，画布和右侧二选一显示，避免两个输入视图争抢光标。
- 编辑时保留四角手柄，调整框宽高实时重排；字号独立修改，不拉伸字形。
- 输入态上沿显示紧凑移动条；点击右侧文本条目切回检查器输入。
- 正文、字号、颜色和宽高订阅真实 Change 事件，合并后台保存，仅替换该文本层。
- 保存按钮复用文本局部提交，保留 A3 背景、图片 GPU 纹理、页面列表和输入焦点。
- 缩略图在输入暂停后异步更新；空闲采样结束，不使用持续刷新伪装实时输入。
- 大字号行高按字号的 1.2 倍设置，避免原生输入默认固定 rem 行高导致重叠。

## 2026-10-21 选字、原生设置与默认信息同步

- 输入态不再保留底层文本框鼠标拖动命中；正文按下/拖动交给原生输入选区，移动仅在上沿、缩放仅在手柄发生。
- 保持三栏、A3 与原有字号/颜色/宽高位置，在其下方加紧凑粗体/斜体/下划线/删除线和对齐操作。
- “更多文本设置”在右侧原有滚动区内展开，不挤压中间纸张；字符、段落、文本框、OpenType 四组。
  每组可搜索属性、显示真实当前值、选择或填写新值、应用；复合原生数据使用 JSON 输入。
- 字体默认微软雅黑；更多设置允许改字体/样式。原生属性目录来自实际依赖，包含110字符、117段落、27文本框属性；字体提供的OpenType特性/样式集另列。
- 快捷字号/颜色保持整框语义；高级字符设置与装饰可作用于选区。段落选项作用于所选段落，文本框选项作用于整个框。
- 高级属性应用后使用原生排版图层呈现，输入态仍用原生普通文本控件；复杂分栏/两端对齐/CJK排版不伪称在输入态逐字与发布排版一致。
- 设置中字段/默认信息有效修改自动保存；编辑页下拉立即读取缓存快照。保留手动保存入口，空白编辑行不作为默认信息保存。
- 不自动覆盖页面已填写内容；新自定义字段显示为空值和可选下拉，用户选择后才进入页内信息条。

## 2026-10-21 检查器层级与实时预设菜单

概念图：[WorkCrate 右侧检查器](workcrate-inspector-2026-10-21.png)。

- 右侧检查器保持在独立滚动栏中，A3 画布和左侧缩略图位置不变。字段用紧凑横向行，分区标题用细主题分隔线建立层级，不添加厚重卡片边框。
- 每个字段保留“标签、当前值、相邻下拉”同一行。下拉打开时从 Projects 服务读取最新预设，已挂载的编辑器不依赖旧菜单闭包。
- 页面文本位于页面内容之后，链接图片仍在文本之后。检查器修整不改变画布和页面结构。
- 页面字段、图片、裁剪和文本删除等局部写入只更新当前页面模型、A3 信息条和该页缩略图；未变化页面卡片及链接图片纹理保留身份。普通项目/页面导航只在选择实际变化时重载目录；同页 MCP 写入通过显式修订号触发该页刷新。项目图片批量更新可刷新受影响的全部页面。
