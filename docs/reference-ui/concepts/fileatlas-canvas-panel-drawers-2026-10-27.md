# FileAtlas Canvas: 四个可折叠面板（2026-10-27）

概念图：[四面板抽屉布局](fileatlas-canvas-panel-drawers-2026-10-27.png)。它延续 2026-10-26 的画布工作区与紧凑侧栏参考，将四个常驻内容区域改成两侧按钮轨道与独立抽屉。生成图展示左侧“画板”和右侧“对象”同时展开的代表状态；按钮轨道中的“资源”和“图层”分别切换同侧抽屉内容。

## 实现清单

- FileAtlas 全局导航与画布窗口外框保持原位。画布仍是最大工作区，点状网格及左右按钮轨道沿用现有行为；标题移到左轨顶部，画板与资源按钮排在标题下方。画布无整宽标题/状态框。
- 底部工具栏居中为同一行三个分开的背景胶囊：撤销/重做、绘图工具、颜色/字体/模板。保存状态以无框文字放在工具栏下方的画布顶层；扩展工具面板在工具栏上方独立显示且不重叠。
- 画布工作区在内容区左右各有一条窄按钮轨道。左轨固定显示“画板”“资源”，右轨固定显示“图层”“对象”；使用语义图标、清楚名称、原生选中态及 tooltip，不把操作藏进顶部工具栏。
- 底部绘图工具栏中的形状、连接线、资源/图像组扩展工具显示在底部工具栏上方的单独面板中；所有组共用固定位置，与工具栏留出清晰间距，不按组按钮计算坐标。
- 同侧同一时间只展开一个抽屉。点击另一个按钮切换抽屉；再次点击当前按钮或抽屉标题中的折叠控件将其收起。左右两侧彼此独立，可同时展开一个左侧与一个右侧面板。默认两侧抽屉收起，完整显示画布。
- 抽屉沿边缘占用工作区宽度而不盖住画布；左侧画板/资源抽屉约 240px，右侧图层/对象抽屉约 290px，随窗口宽度收缩并在内容过长时独立纵向滚动。窄窗保留可触达的按钮轨道与折叠操作，不让行内按钮挤到下一行。
- “画板”抽屉标题区包含新增入口；当前画板名称输入、重命名动作以及导入、导出、删除、图片缓存刷新等当前顶部画板操作迁入该抽屉。画板列表继续显示名称和激活态；新增、重命名以及菜单操作执行现有 WhiteboardService 行为。窗口顶部不再放画板编辑/新增按钮，只保留当前画板名称提示。
- “资源”抽屉承载现有文件/视频资源列表；保持类型图标、解码后的名称、类型参数和打开动作，不增加搜索或分类过滤。
- “图层”抽屉单独显示当前画板图层，继续支持选择、置顶顺序和同一行上下移动；无图层时显示明确空状态。
- “对象”抽屉单独显示所选对象属性。保留图标加参数、尺寸/位置、复制、本地路径及 Eagle 来源/定位行为；无选中项时显示轻量提示，不创建空属性行。
- 所有抽屉、轨道、按钮、选中/hover/禁用状态使用 GPUI Kit 原生 Theme 和 UI Bridge 公共组件；不添加局部调色板、私有边框或新字号。
- 抽屉展开/折叠只改变可用工作区宽度，不改变画布相机、缩放、图层顺序、资源、选中对象或撤销历史。关闭画布后临时展开态不持久化。

## 概念图与实现的范围差异

生成图中的画板搜索框、示例计数、对象尺寸输入和部分装饰图标仅用于表达信息层级，不属于本次功能。实现沿用现有真实数据与只读属性行为；不会添加搜索、计数或属性编辑功能。

## 状态验收清单

- 默认：左右抽屉均收起，四个按钮轨道可见，画布保持最大宽度。
- 左侧：分别打开画板和资源；点击当前按钮折叠，切换按钮替换内容；画板新增/重命名/导入/导出/删除/刷新均在面板内操作。
- 右侧：分别打开图层和对象；点击当前按钮折叠，切换按钮替换内容；核对图层空/多行、对象无选择、普通图片和 Eagle 图片属性。
- 双侧：同时打开一个左面板与一个右面板；检查画布最小可用宽度及绘图工具仍可操作。
- 小窗口与长内容：两侧抽屉各自滚动，轨道按钮与关闭入口可用；长画板名、文件名和 Eagle 路径不溢出。
- 悬停、键盘焦点、选中、禁用边界、保存/错误状态继续使用原生主题与已有行为。
