# 低饱和度语义主题清单

本次概念用于全局配色和对比度方向。它保留 PhoTag 0.2 主窗的左侧图标轨、文件夹导航、工具栏/搜索、缩略图区、检查器及状态栏，不取代各功能画面的活动布局稿。

## 颜色层级

- 两种模式共用结构：暗色用石板蓝灰表面和柔和浅字；亮色用雾灰与柔白表面、深石板字。
- 表面按 base → panel → card → elevated 区分，modal/input 单独命名；薄边框仅用于可辨识分区。
- 正文、辅助正文、弱化正文分别用 primary/secondary/muted token。弱化文字仍需在所属表面上可读。
- 强调色采用低饱和度蓝灰；危险、警告、成功、收藏、分类及数据色均使用低饱和度语义色。
- 所有填充控件须有配对的前景色。共用对比度函数根据实际填充色计算黑/白前景；状态色文本使用对应的 on-color token。
- 选中状态保持背景色和文本色两者可辨；hover/pressed/disabled/focus 沿用 GPUI Kit 或共享组件状态。

## 检查状态

- 默认与调整后的强调色、浅色和暗色均检查。
- 检查实心主按钮、危险按钮、警告/成功徽标、中性按钮、禁用按钮、文本输入、选中行及菜单。
- 照片、用户自定义标签色和操作系统图标仍是内容数据，不被主题重染。
- 运行截图需逐项比对按钮底色与文字、输入底色与输入文字、主要/次要文字、边框和层级，并确认无遮盖。

## 用户截图对比修正清单（2026-10-19）

- 保留截图中网格、角标位置、标签行与左导航布局，本次仅修复前景和背景配对。
- PNG/PSD/IPK/ZIP/TOML/PY/SVG/无扩展名角标：使用集中管理的低饱和度格式色；文字依据角标实际底色计算，不借用主题按钮的前景色。
- 缩略图标签：色彩混合到当前卡片表面，使用不透明底，确保黑白照片上均可读；文字和图标分别依据胶囊的实际底色校正。验证紫、蓝、黑、白、黄自定义色及普通/选中状态。
- 评分、播放和溢出计数：暗色图片徽标使用独立成对前景，不随亮色正文变为深色字。
- 左侧选中导航：前景依据选中底色求可读颜色，不使用更浅的 hover 填充色画字。
- 同进程 MCP 在亮/暗模式实际打开带格式文件、彩色标签、评分的本地隔离目录；查看截图，并检查实际角色函数的对比度。

## 原生主题迁移清单（当前）

用户要求颜色完全由 GPUI Kit Theme 分发，Material 仅生成 JSON。概念图继续指导低饱和与可读性，不再要求保留旧手写 RGB。
- 保持工作区/导航/网格/检查器结构；原生 Default 与 Material Neutral 均使用同一布局。
- 自绘标签、文件角标、导航、浮窗、设置及工具插件都读取原生角色。
- Material 设置页复用现有声明式设置页：种子输入、风格、对比度，生成位置与生成/应用两行操作。
- 实测框架默认亮暗、Material 两种种子，主窗/设置/剪贴板/启动台/菜单、小窗与重启恢复。
