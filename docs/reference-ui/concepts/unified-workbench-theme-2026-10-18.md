# 全局工作台主题：以剪贴板 v2 为基准

用户 2026-10-18 明确要求：以当前剪贴板面板样式统一整个软件及全部插件，并抽取通用组件，规定未来开发方式。本次覆盖旧 v5 石墨灰**样式**，保留各活动参考规定的功能布局、控件顺序和状态。

## 编码前核对清单

- 根背景 #0e1823，区域 #152230，卡片 #1b2a3b，输入 #101b27，边框 #304357，正文 #e7eef7，辅助 #9eafc5，默认蓝 #2787ff。颜色只由 UI Bridge theme 提供。
- 主窗仍为工具带、导航、媒体区、右侧检查器和底部状态栏；剪贴板仍三栏；启动台仍分类/图标网格/详情；设置仍左导航、右侧横向设置行、固定页脚。不得把所有插件强制改成同一个业务布局。
- 浮窗复用 panels；内容卡、选中卡、导航行、按钮和标题使用共享组件。面板间距 10，正文内边距 12–16，卡片圆角 8，按钮圆角 6，输入/普通按钮高度 32，重要操作 38，紧凑图标按钮 30。紧凑树行保留 30 高度。
- Segoe UI 正文 14、辅助 12、细注 11、分区标题 15、页面标题 18；标题/正文/次要文字有稳定层级，使用 Lucide 图标。缩略图标题和高密度表格允许辅助字号。
- 选中使用主题色边框和主题色调背景；hover 不能覆盖选中，主按钮/次按钮有正常、hover、pressed、disabled、focus；颜色改变后全部插件同步。标签用户色、图像、系统程序图标属于数据，不被主题重染。
- 菜单/对话框/统计/导出/批量操作/历史/开发工具均使用同一语义色。错误红、警告琥珀、成功绿，不能把每个插件的任意装饰颜色当成新的主题。
- 默认尺寸下操作完整；缩窗时正文滚动、操作可达；长文本截断或换行遵循原业务布局。保持已有分栏宽度恢复、浮窗拖动和调整大小。
- 同进程 MCP 对照主窗、剪贴板、启动台、设置、菜单和辅助浮窗；对照默认、小窗口、选中、焦点、空态和真实变化；记录未进入的状态，静态检查不替代运行证明。
