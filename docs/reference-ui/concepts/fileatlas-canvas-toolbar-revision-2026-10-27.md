# FileAtlas 画布标题、状态与工具栏位置（2026-10-27）

![画布工具栏调整概念图](fileatlas-canvas-toolbar-revision-2026-10-27.png)

本稿落实用户提供的标注截图。保持现有画布内容、四面板抽屉及左右轨道，不改变工具行为；重排画布插件内的标题、状态和工具控制。

## 实现清单

- 移除画布视图顶部整宽标题区和底部整宽状态框，画布与左右轨道占用完整可用高度。
- 将“画布”及当前画板名称放在左侧轨道顶部。画板、资源按钮在标题下方依次排列；右侧图层、对象轨道不变。
- 底部画布顶层居中放置一行三个独立面板：左侧撤销/重做，中间选择/平移/文字/形状/连接线/资源工具，右侧颜色/字体/模板。面板间留出间距，背景互不连通。
- 形状/连接线/资源工具的扩展选项保留在该行上方的单独弹层，并与工具栏保持空隙。
- 保存/保存失败状态移至工具行正下方，作为画布内无框辅助文字；保存失败时保留重试入口与错误信息。
- 窄窗下工具组可换行，但三组背景仍各自独立，状态仍在工具组下方，不覆盖画布轨道按钮或交互目标。
- 控件沿用 GPUI Kit Theme、UI Bridge 组件、工具提示、焦点/禁用状态与现有保存/撤销语义。

概念图中的画布图形、素材、样例文字和对象属性是装饰示意；实现继续显示真实画板数据。概念图使用浅色预览，实际主题由 GPUI Kit 当前 Theme 决定。
