# 插件设置中心：布局与行为清单

日期：2026-10-18。依据新增的插件设置中心概念图 `plugin-settings-hub-2026-10-18.png`，并延续 `shortcuts-settings-2026-10-18.png` 的设置窗口框架与统一深蓝主题。

## 页面结构

- 复用当前可拖动/缩放设置浮窗，窗口顶部和固定底栏保持现状。
- 左侧导航按两个分组组织：`程序设置` 包含现有外观、快捷键、标签、AI、更新、软件页，以及新增的插件总览；`插件设置` 按每个已注册插件生成独立页面入口。
- 右侧正文可滚动。插件总览按卡片显示图标、名称、简介、设置页入口及启停开关；卡片不以主窗口中的扩展入口替代。
- 单个插件页按运行时注册表动态生成。当前公共页显示插件说明、可用的启动呈现方式与打开插件面板入口；更复杂的插件专属设置控件仍需各插件接入后续设置视图注册接口。
- 沿用 14px 正文、12px 辅助说明、8px 卡片圆角、12–16px 卡片内边距和 10px 分区间距；选中态使用统一主题强调色，卡片边界使用统一 hairline。

## 状态和行为

- 每张插件卡显示真实运行状态。启停操作调用 Cordis Fiber 的 dispose/spawn 生命周期，相关快捷键、面板、事件订阅和后台任务由 Cordis 插件清理流程管理。
- 当前仅将独立启动的启动台、剪贴板和截图工具注册为可停启插件。依赖关系复杂的核心插件尚未出现在可停启列表中；需要在加入前实现消费者/依赖编排，避免产生无效开关。
- 停用后插件设置页显示已停用状态和已保存设置入口；设置文件不得因停用而删除。
- 动态注册项在 Cordis stop 时从卡片和导航中移除；重启后按新的注册代次重新出现。
- 小窗口下正文滚动，左侧导航与固定页脚保持可见；长名称截断但可通过 tooltip 获取完整名称。

## 本次实现范围

首批集成启动台、剪贴板和截图工具。插件总览和独立设置页从公共运行时注册表生成；启动台、剪贴板可选主窗+浮窗或仅浮窗，截图可选这两种及直接调用 Shotoshot（默认）。其他插件需先接入可停启生命周期；插件专属设置视图注册与依赖启停编排尚未实现。

运行验收须核对默认/修改后的强调色、三种启动策略、开关的 Fiber 停止与重启、面板/快捷键清理、依赖插件拒绝/级联行为、设置页切换、小窗口滚动，以及关闭/重开后的持久化状态。

## 2026-10-18 用户纠正：仅浮窗必须是独立窗口

追加前台验收：快捷键首次打开和再次唤起的独立窗口都须置前并获得焦点。
检查 Windows GetForegroundWindow 等于目标 HWND，不能仅凭 visible 判定通过；
主窗保持最小化。不增加永久置顶策略或定时抢焦点。

本次范围是行为修复，不重排设置页或插件正文。用户明确选择“插件独立窗口，不拉起主界面”。
对照 settings-clipboard-2026-10-18.png：设置导航、两项策略、快捷键横行、工具入口、固定页脚保持；
“仅浮窗”的说明改为“独立打开工具窗口，不唤起主界面”。

验收清单：
- 仅浮窗创建独立原生窗口，正文填满该窗口，无空白主窗背景；主窗最小化状态保持。
- 主窗可见时内容完整保留，不隐藏图库/侧栏；独立窗口不占主窗 modal 层。
- 同一工具重复打开复用并激活原窗口；不同工具可以同时独立打开。
- 关闭按钮/Escape/插件停用关闭实例，Cordis 保留数据；重新打开重新创建实例。
- 切回“主工作区与浮窗”恢复主窗并使用原有公共浮窗，切换方式不产生重复实例。
- 原生窗口标题/拖动/缩放/关闭由系统窗口 chrome 提供；正文主题仍为公共深蓝主题。
- 最小尺寸和长内容使用各插件原有约束与滚动；检查原生窗口 quiet-state 与真实交互。

原生标题栏是本次独立窗口功能所需的针对性变化；不添加新桌面悬浮按钮，不改变 JSON 设置枚举。
