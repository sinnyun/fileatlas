# 浅色工作台主题清单

本次实现 PhoTag 0.2 的浅色主题模式；暗色模式仍以
[统一工作台主题概念](unified-workbench-theme-2026-10-18.md)为准。浅色图是配色和主题按钮状态参考，
不是对业务布局的重排要求。

## 可检查的结构与状态

- 主窗继续保留标题栏、48px 左导航轨、文件夹侧栏、横向操作带、媒体网格、右侧检查器和底部状态栏。
- 左导航轨底部的亮/暗切换在设置按钮正上方；两者由 Settings 插件通过 `workspace.sidebar-footer` 托槽贡献。
- 浅色层级：根背景 `#f3f6fa`、面板 `#e9eef4`、卡片 `#ffffff`、输入/凹槽 `#e3eaf2`、边框 `#c3cfdd`；正文 `#1b2735`、辅助正文 `#465a70`、弱化文字 `#61758a`。强调色保留工作台蓝 `#2787ff`。
- 卡片圆角 8、控件圆角 6，维持 4/8/12/16px 间距节奏和现有密度。选中、悬停、禁用、焦点继续使用共享 Kit/组件语义。
- 切换时更新共享主题和所有模式相关语义 token；设置 JSON 保存 `color_mode`，缺省为 `dark`，旧 JSON 无迁移要求。

## 状态范围

概念图展示普通、选中、悬停、禁用控件，以及主题按钮悬停、设置按钮静止状态。实际 GPUI 窗口仍需通过同进程 PhoTag MCP 核对上述状态、小窗口和至少两个功能插件；静态编译不作为视觉验收。
