## 四种内容状态

- **程序信息**：没有活动选择对象时显示 PhoTag 标识、浏览概览、当前浏览位置、浏览状态和使用提示；概览只显示当前结果数、当前可见子文件夹数、标签数量和应用版本，不出现任何具体标签名或标签树。PhoTag 是本地照片浏览与管理程序，没有媒体库对象、注册图库容量或磁盘占用面板。
- **标签信息**：显示标签自身颜色、层级路径、父标签、媒体数、子标签；名称可在面板内直接修改，颜色用快速色板修改，缩略图显示设置可在面板内切换。写入复用 Navigation 服务；当前不复制图标、关联关系和批量应用到子标签的编辑能力。
- **文件夹信息**：显示名称、完整路径、当前浏览结果数、可见子文件夹及浏览状态。未打开目录的未知计数明确保留未知，不显示索引或扫描字段。
- **文件信息**：继续保留现有缩略图预览、评分、信息/历史/扩展分页、基本信息、彩色标签胶囊、EXIF、路径和文件操作。历史页以分支树/缩略图/创建与切换控件为主，版本元数据收为次要信息；普通运行只呈现真实当前文件节点和无历史版本状态。设置 `PHOTAG_DEMO_INSPECTOR=1` 的显式视觉验收运行会加入标注未保存的分支样例，供对照概念图，不读写历史数据。

## 层级与视觉节奏

- 右栏仍使用现有固定宽度与既有面板表面；对象身份置于顶端轻底色信息块，图标用对象或标签本身的颜色突出。
- 区块标题采用清楚的半粗体，字段名使用次级文字，数值与内容保持主文字对比；行间使用细分隔线，避免信息粘成一团。
- 信息块约 12–14 px 内边距，字段行保持紧凑，主分区之间留出约 10–14 px；长路径与字段值受限宽度并截断，主体在窄高窗口中独立滚动。
- 标签的色块、子标签和已存在的文件标签胶囊直接反映数据库颜色；不以通用蓝色代替用户标签色。
- 文件上下文才展示现有预览与信息/历史/扩展分页；程序、标签、文件夹上下文使用自己的身份头和详情正文。

## 与概念图的实现差异

概念图中的统计数值、状态示意和分支版本均仅供视觉参考。程序面板只呈现当前浏览结果、可见子文件夹、实际当前位置及程序包版本，不伪造磁盘容量、媒体库、扫描任务或标签明细。标签概念图中图标、关联关系和完整编辑选项代表未来扩展方向；目前面板内提供名称、颜色与显示开关，保持其余现有编辑能力可由 Navigation 原编辑器访问。历史快照接入和创建/切换行为仍待用户后续确定；普通运行中的两个按钮清晰可见但禁用，不写入伪造版本数据。只有同时启用 `PHOTAG_DEMO_INSPECTOR=1`、dev-test及隔离profile的截图验收进程展示内存模拟节点及创建/切换交互。首轮缩略图占位实际由不存在的路径造成；完整v2验收已使用有效JPG验证照片缩略图，见最新运行证据。
