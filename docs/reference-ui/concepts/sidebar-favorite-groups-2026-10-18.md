# 独立收藏分组栏

依据用户本轮两张截图：保留[第二张的分组结构](sidebar-favorite-groups-user-reference-2026-10-18.png)，
使用驱动器/快速访问当前深蓝样式。[内置 ImageGen 概念](sidebar-favorite-groups-2026-10-18.png)
已打开检查，只采纳结构、对齐和组件关系，不复制渐变、巨大字号或示例路径。

编码前清单：

- 驱动器、快速访问、每个收藏分组都是平级独立边框块，使用同一个 frame/header 构造器。
- 删除外层“文件夹收藏”、内部“库文件夹”“收藏集合”和总“收藏分组”标题；不再嵌套整组。
- 每组标题为左侧折叠箭头/辅助色标题，右侧省略菜单/＋；与上方两区字号、内边距、行高和边框一致。
- 每组自己的＋直接读取已导航到的主窗文件夹地址并加入该组，不打开路径表单或原生选择器。
  Home/标签集合没有文件夹地址时禁用＋；已存在不重复添加、不覆盖别名；动作时重新验证目录/组。
- 文件夹行保留懒展开/选中/右键管理，优先显示完整路径，长路径截断；用户真正重命名的别名保留。
- 原数据库收藏导入默认“常用”组，既有自定义组及顺序保留；存入已有 Settings SidebarFoldersConfig。
  保留数据库登记/扫描/监听，不把删除收藏误当成删目录或删库。导入标记避免删除后重启又复活。
- 新建分组入口独立位于所有组后，行内新建/重命名编辑器放在对应分组。无分组时仍有新建入口。
- 默认、多个分组、空分组、折叠、重复添加、长路径/别名、小窗滚动、保存/重启恢复及静置均用同进程 MCP 验证。

ImageGen 提示：两张用户图作为参考，保留现有深蓝（root #152230、frame #101b27、border #304357）
与紧凑字体；驱动器、快速访问、常用/AI/工作分组独立框，统一 chevron/title/ellipsis/plus，
组内 folder path rows，底部新建分组，不出现旧复合标题或搜索框，＋意为即时收藏当前文件夹。
