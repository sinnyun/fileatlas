# 文件暂存篮面板概念与实现清单

初版概念图：`file-staging-basket-2026-10-20.png`。本次用户要求采用网格卡片后，活动概念更新为
`file-staging-grid-drag-2026-10-20.png`（ImageGen built-in）。

## 结构清单

- 独立通用浮窗；标题与项目数在同一行，添加/刷新/清空操作靠右。
- 内容区为可滚动、响应式换行网格；每卡优先显示真实图片缩略图和文件标题，来源路径为次级信息。
- 卡片可点击选择，Ctrl 点击切换多选；拖动单卡或所选卡片组时显示缩略图拖拽影子。
- 失效文件显示降级图标和不可用状态；图片解码失败也降级到主题文件图标。
- 空篮有居中空状态说明。
- 底部固定状态与“复制到…”入口；拖放到 FileManager 子文件夹分组即按程序现有默认语义执行移动，不出现复制/移动选择对话框。
- FileManager 子文件夹成为有效 drop target 并显示高亮；结果反馈报告移动成功/失败数。
- 保留共享 Workbench 卡片、主题角色、原生按钮状态；不在插件自定义颜色。

## 当前实现差异

- 非图片文件使用主题通用文件类型图标；图片文件直接加载真实图像预览，尚不为篮外文件生成额外缩略图。
- “刷新状态”在后台阻塞池检查路径并写入缓存；列表渲染只读该缓存。
- 忙碌状态覆盖文件选择器和转移流程，进度目前显示为阶段提示，不表示逐文件实时百分比。
- 拖放采用 FileManager 既有目录分组目标和默认移动语义，不改变用户操作认知；复制仍由明确的“复制到…”命令启动原生目标选择器。
- 网格需在小面板宽度下自适应列数；空态/失效、长标题和窄窗视觉对照仍待补验，运行截图位置见同日验证记录。
