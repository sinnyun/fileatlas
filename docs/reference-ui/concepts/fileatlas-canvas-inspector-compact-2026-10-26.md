# 画布信息侧栏紧凑化清单（2026-10-26）

概念图：[左右侧栏优化方向](fileatlas-canvas-inspector-compact-2026-10-26.png)。依据用户提供的实际画布截图；是现有 tldraw 布局的局部补充，不取代其中心画布和工具栏结构。

## 可检查结构

- 窗口顶部和中心无限画布保持原位置与比例，左/右面板沿全高独立滚动；不增加遮盖画布的常驻弹窗。
- 左侧先列画板，再列资源；画板名和资源名各占一行主信息。资源行由文件类型图标、解码后的文件名、次要类型/扩展名构成；路径不再充当主标题。
- 右侧依次为图层列表和选中对象属性。每个图层一行，左侧类型图标与截断名称，中间弹性留白，右侧仅有上下箭头按钮；按钮仍可触发原先的图层顺序修改。
- 属性按用途分组，数据行由语义图标、短值和必要的复制操作组成。位置/大小采用图标加数字参数；Eagle 名称/文件夹直接显示值。长地址显示尾部路径或短标识，完整内容由 tooltip 与复制动作提供。
- 所有面板、行、按钮状态走 GPUI Kit 原生 Theme 和 UI Bridge 共享组件。保持既有三层字号和紧凑/标准/宽松间距，不引入本地色板、私有边框或新字号。

## 状态

- 无选中项：显示轻量的未选中提示，不生成空的属性行。
- 选中项：行选中态保持主题强调色；上下移动边界动作禁用且提供 tooltip。
- 长名称/路径：列表与属性不横向溢出；名称截断，完整路径可悬停查看并复制。
- Eagle 图片：显示来源名称、所属文件夹、原图路径、统一资源 URI、缩略图路径和 API URL 的紧凑呈现。
- 普通图片/文件：仅显示实际可用的文件名、尺寸/位置或资源类型，不出现 Eagle 占位字段。
- 小窗口：侧栏内容正常纵向滚动；关键行内操作保持同一行，不把图标按钮挤到下一行。

本轮不实现概念图中的资源分类标签/搜索、画板计数、样式 Tab 或每项更多菜单；这些超出用户本次指定的左右面板信息展示范围。

- Eagle source details include a compact external-link icon action to open and
  locate the current item in Eagle; it sits right-aligned above the metadata rows.
