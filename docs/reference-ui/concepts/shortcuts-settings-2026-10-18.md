# 快捷键设置页：当前实现与验收清单

活动参考：[shortcuts-settings-2026-10-18.png](shortcuts-settings-2026-10-18.png)。
2026-10-18 用户指出上一轮实现没有按图修改，本说明将图中结构转成可核对要求。
本稿覆盖 v5 sheet 02 的快捷键页，其他设置页继续沿用原基线。

## 画面结构

- 共享可移动/缩放设置浮窗，左侧深色分类栏、右侧正文、底部固定自动保存说明与关闭按钮。
  默认面板请求 1120×840 逻辑像素，受宿主可用区约束；最小 920×580。尺寸是实现取值，
  不是生成图片的像素标尺。默认大窗口在两个插件快捷键下显示完整 F1–F9；受限窗口可滚动。
- 正文先是“快捷键”标题及范围说明，其下为“插件快捷键”横向行，再为“其他快捷键设置”。
  各组细线分隔，标题 22、分组 16、主要内容 14、辅助说明 12 逻辑像素，正文内边距 20。
- 每个插件绑定独占一个横行：命令名及信息入口 → 作用范围徽标 → 按键框 → 更改/恢复/禁用。
  所有行使用同一列宽和右边界。操作不另起一行，按键框不漂到最右端而丢失操作列。
  信息入口提供所属插件、范围说明和默认键，避免把内部插件 ID 作为常驻副标题。
- 自动读取所有插件登记项，顺序沿用命令目录；不可只画两个硬编码样例。
  默认宽度下名称区 190、范围 66、按键 130，控制区按剩余宽度伸展；长名称省略并在信息提示中可查。
- 其他快捷键依次为排除修饰键、打开媒体文件、评分说明、F1–F9 标签。前三项为分隔行，
  左侧名称/说明，右侧修饰键菜单或按键/更改。移除重复的外层小节标题。
- F1–F9 单列九行，左侧紧凑键帽，右侧标签选择器铺满剩余宽度，放在一个边框区域内。
  不保留旧的 360px 选择器宽度导致右边大片空白。真实标签显示自己的色彩/图标；“Nature”
  和“Landscape”只是图中示例，不写入用户设置。

## 状态与可操作性

- 正常：作用范围区分“程序内/系统级”，后者在任意前台应用可生效；按键清晰可读。
  恢复和禁用采用较轻操作样式。系统级实际注册仍由 shortcuts 插件负责。
- 录入：同一行用蓝色边框/淡蓝填充的录入框替代按键与操作区，显示组合键提示、键盘图标
  与可点击的“Esc 取消”；不只把更改按钮文字改成“正在录入”。
- 冲突：由真实重复绑定触发，录入框下红字指出占用命令；不写入设置，保持录入以便重试。
  Esc 或取消结束录入并恢复原值；关闭/切页也释放录入态和临时停用的系统键。
- 禁用：显示“已禁用”；恢复删除覆盖值并重新采用插件默认键。成功录入即时保存，重开仍有效。
- 排除修饰键保留原语义：按住修饰键点击标签排除。图片中“按住后不触发标签键”的文字属于
  生成瑕疵，不改变原有业务语义。QuickLook 继续是媒体文件的打开方式。
- 空注册/标签读取中/失败均显示真实状态，不伪造插件、标签或红色错误。

## 明确的适配差异

不恢复已被用户删除的旧“工具栏”分类，不逐像素复制渐变、阴影、徽标或光晕；沿用主题
token 和共享浮窗标题栏。参考图的两个插件排列顺序为示例，实际按生命周期命令目录排列。
小窗口可纵向滚动，但不得把横向插件行改成两行按钮或把页脚滚出可用区。
剩余偏差必须在运行证据中列出，不能只引用本说明作为完成证据。
