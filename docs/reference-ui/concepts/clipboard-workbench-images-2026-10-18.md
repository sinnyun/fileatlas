# 剪贴板图片与混合内容补充

沿用 [剪贴板工作台 v2](clipboard-workbench-layout-2026-10-18-v2.md) 的三栏结构与
统一深蓝主题。本轮只为实际复制的图片增加内容预览和类型筛选，不改变标题、搜索、分组、
收藏、正文编辑等既有操作。

## 实现清单

- 左栏保留历史/收藏/未分类、类型筛选、用户分组和监听暂停入口；增加真实“图片”类型，
  计数来自数据库中的图片记录。
- 中间历史区保持自适应宽度、按日期分组。图片记录显示缩略图、像素尺寸、时间、分组和收藏状态；
  文本记录继续显示短文本预览。选中图片仍使用原有蓝色边框/选中底色。
- 右栏保留编辑信息和分组。选中文本时保持原来的文本编辑框；选中图片时改为完整比例预览，
  显示尺寸与“复制到系统剪贴板”操作，底部关键操作仍可见。
- 常态、图片选中、文本选中、空历史、无效图片、小窗口与长文本都使用真实服务数据；
  图片损坏时显示文件图标和错误状态，不崩溃。
- 采集时只读取 Windows 剪贴板格式并写 FileAtlas 自己的数据库/图片缓存；绝不调用写入、清空或
  重新设置系统剪贴板的 API。用户显式点“复制到系统剪贴板”才会替换当前系统剪贴板内容。
