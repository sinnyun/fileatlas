# 全局八类语义色概念与实现清单

概念图：[八类语义色工作台](unified-eight-family-theme-2026-10-24.png)。沿用 FileAtlas 0.2 主窗的图标轨、左侧文件夹导航、顶部工具栏、中央文件视图、右侧检查器和底部状态栏；此概念只更新全局颜色系统，不重排各页面。

## 八类语义色

“最多八色”按八种可配置的语义色类执行；GPUI ThemeConfig 的亮/暗、前景/背景、hover/active 对比状态可使用同一类的明暗色阶，不作为新增语义色。八类为：中性表面、正文、主色/交互、次要色、成功、警告、错误、信息。边框、焦点、选中、悬停、图表、格式标识和状态控件必须复用这八类及其色阶，不另外产生颜色类。

照片像素、系统图标、用户设置的标签色，以及 VectorCraft 文档画布中的实际艺术内容属于内容数据，不纳入 FileAtlas UI 主题色。插件不得用它们来绘制插件自身的卡片、导航、按钮、文本或状态。

## 可检查的实现清单

- 窗口仍按既有左侧导航 / 中央文件区 / 右侧检查器比例工作；工具栏与地址栏关系不变。
- 背景、面板、卡片、输入框、弹层和分隔线仅用中性表面/正文两类的色阶。
- 顶部 Ghost 按钮、导航文件夹行、文件夹卡片、可选行和表格行的相同交互状态使用同一主题角色；选中、hover、focus 与 pressed 的差异使用同一主色类的深浅阶。
- 主要操作、次要操作、成功/警告/错误/信息提示分别使用对应语义类；每种填充始终配对原生前景角色。
- 小图标、评分、图表与格式徽标只引用八类语义色，不按插件或页面新增 palette。
- 亮/暗模式保持相同语义映射；选择器展示八类的名称和当前值，移除任意原生角色独立输入色。
- 主题由 Material 插件生成 GPUI ThemeSet。UI Bridge 是所有自绘通用组件的主题投影层；功能插件只选择公共 SurfaceRole / ForegroundRole / shared style，不计算或保存 UI 颜色。
- 检查默认与自定义强调色；常态、悬停、选中、焦点、禁用，以及亮/暗模式；额外检查设置页、主窗、左侧树行、中央文件夹卡片、检查器和插件面板。

## 不允许的分叉

- 相同 hover 状态不能同时使用彼此无关的 `accent`、`list.hover`、`table.hover` 或按钮局部颜色。
- 同一状态的语义颜色不能在 UI Bridge aliases 与 ThemeSet 生成器里有不同指向。
- 插件不得自行创建 HSV/RGB 表、文件类型 palette、快捷方式色表或局部主题 token。
- 只有实际内容的用户颜色和媒体像素可保留为数据色；组件需通过公共主题前景配对 API 保证文字可读。

图片只规定颜色层级与典型状态，不是对业务内容和像素布局的要求。
