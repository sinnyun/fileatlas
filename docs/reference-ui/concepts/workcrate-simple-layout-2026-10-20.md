# 固定 A3 图片排版页：用户语义纠正

用户最新说明覆盖之前“通用画布”的理解。沿用已选三层视觉参考的栏目位置与层级，
但编辑内容只有固定 A3 纸上的信息条和图片放置区。

- 项目管理 → 页面管理 → 页面编辑保持三层。编辑页左页面栏、中央固定 A3、右检查器。
- A3 横向 420×297 mm 是真实页面和默认导出尺寸。没有页面尺寸编辑，也不平移整页。
- 页外名称、尺寸标记、像素是查看资料；尺寸标记自由填写，不参与图片或页面缩放。
- 页内顶部是项目名、物料、尺寸、数量等信息条；下方才接收图片并显示编辑手柄。
- 图片链接本地 JPG/PNG；保留原始文件路径与内容摘要，不破坏源文件。
- 图片操作只有位置、四角等比缩放、可恢复裁剪。裁剪改变原生 DesignCraft frame，
  内容比例不变；恢复使用上游 Fit Frame to Content。禁止自由拉伸和旋转入口。
- 拖动中只更新缓存图片图层，不写文件、不重新装载整个项目、不重绘整页。
  松手一次提交 DesignCraft resize；异步更新该页缩略图。
- “更新项目图片”遍历全部页面链接，替换已变化的图片并刷新画面；失败逐项报告。
- 每图有单独的扩展源文件链接（如 PSD）。编辑源文件复用 File Operations 的系统关联打开。
  用户在 Photoshop 修改 PSD、导出覆盖原 JPG/PNG 后，再点项目更新。程序不替代 PSD 导出。
- 导出由 DesignCraft + PdfCraft 负责，范围只有固定 A3 上的信息条和图片。

持久化兼容：`PageInfo.size_label` 是新增可选默认字段。旧 `physical_size_cm` 只作标签，
不再驱动 documentSetup。旧产品页（order>0）在读入时纠正为 A3，保留图片坐标；
后续正常保存写入原目录并保留 .bak。没有删除或重编码原图。


## 本次性能改动的界面清单

- 保留三层导航、三列页面卡片、编辑页左右栏和固定 A3 信息条/图片区。
- 页面管理优先显示持久缩略图；缺失时使用现有占位并逐页后台补齐。
- 图片位置/裁剪/比例及四角手柄保持，按设备像素请求显示代理，导出另读原图。
- 现有底部状态区增加当前页/总页数、读取/渲染/编码/写入阶段和完成耗时。
  不新建面板、不挤占正文，导出按钮在实际工作期间继续禁用。
- 暖缓存、原图暂不可访问、导出中/完成/失败及安静状态通过同进程 MCP 检查。
