# 简洁设置中心（2026-10-18）

本轮用户明确要求全面重构设置与内部页面，并在第一张概念后要求进一步简洁。
活动参考为相邻 `settings-minimal-2026-10-18.png`（内置 ImageGen）。覆盖旧设置布局，
沿用剪贴板 v2 的公共主题；此前厚重卡片/大图标概念被否决，不作为验收依据。

## 编码前清单

- 保留公共可拖动、缩放浮窗和既有几何恢复；默认 1120×840，最小 920×580。
- 左侧约 224px 导航，程序/插件两组，小图标、36–40px 导航行；不加装饰身份卡。
- 正文自适应，32–40px 内边距；固定页脚；导航和正文分别滚动。
- 各页一个标题及一句说明；设置按空白/细线分区，不套多层卡片。
- 标签/简短说明居左，操作居右，关联控件保持同一行。字号正文14、辅助12、标题18–22。
- 外观：语言行；强调色横排/换行，保留真实8个预设及System选项；区域分隔二选一。
  不增加图中暗示的主题模式，也不采用生成图中的示例鲜艳色名。
- 快捷键：命令/范围/按键/操作同一行；保留录入、冲突、取消、恢复、禁用；F1–F9正文可滚动。
- 标签：匹配方式、搜索范围、搜索保持、合并策略；AI：自动分析及分组增删改。
- 更新：版本、检查、结果/错误、下载/安装状态；软件：状态、版本路径和项目链接。
- 插件总览：每插件一行，图标/名称/说明/真实状态/设置/启停；独立页提供启动方式和快捷键。
- selected/hover/focus/disabled 使用公共主题；错误放正文，页脚保持可见。
- 小窗允许正文滚动，长文字换行或截断，关键控件不得越出容器；检查默认及修改强调色。

## MCP 插件设置页增补清单（2026-10-19，三档权限修订 2026-10-19）

- 由 MCP 插件通过现有 `settings.pages` 声明式设置页注册，显示在“插件设置”组。
- 单页标题“AI 控制”，简短说明当前进程 MCP 的可操作权限。
- 一个标准 Segments 行作为三档切换：“关闭”“常规控制”“完全控制”。常规档允许界面/API控制与常规信息增删改；完全档额外允许高影响操作。
- 高影响工具在完全档仍要求调用参数 `confirm=true`，保留每次操作的明确确认；完全档不可由 MCP 控制调用绕过设置页自行启用。
- 沿用正文标题、细线分区、标签与说明左/分段选择器右、主题 selected/focus 状态及设置自动保存；不新增独立卡片或全局配置文件。
- 新配置在旧设置 JSON 缺失时默认为关闭；旧布尔值 false 映射关闭、true 映射完全控制。所有 MCP 路由每次调用读取当前 SettingsService 快照，切换无需重启。

持久化、Cordis生命周期、ReadModel和事件语义继续使用现有服务；本轮不更改数据格式。
同进程 MCP 截图和实际交互结果另记入 validation-ui 与 redesign-validation。
