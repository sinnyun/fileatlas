# 多栏主工作区与程序工作区清单（2026-10-19）

活动参考：最新用户标注图 `codex-clipboard-d871cce4-627a-4483-bbe9-4485b6237414.png`（覆盖先前标注图）；按本轮布局生成的概念图见同目录 `multi-column-workspaces-2026-10-19.png`。
两栏或四栏布局由独立地址导航和文件视图内容组成，公共操作带位于这些栏目上方。

## 栏目结构

- 全局左侧栏和右侧检查器保留各一份，不进入分栏。
- 每栏顶部只保留自己的地址导航（后退、前进、上级、面包屑/地址输入）；其下为该栏独立的文件视图内容区域。
- 地址行严格保持单行：后退/前进/上级按钮和打开文件夹/刷新按钮固定不收缩；中间地址区域占用剩余宽度并允许收缩。浏览模式显示可点击的路径面包屑，当前目录段始终可见、上级路径可横向滚动；编辑模式显示可输入路径与 Go 操作。窗口或四栏变窄时不得把末尾操作按钮挤到下一行。
- 第一行公共操作带分成两个独立区域：左侧为筛选、排序、分组、网格/列表、子文件夹显示和缩放；右侧为搜索与通用功能按钮。两组之间保留清楚间隔/分隔，允许后续分别扩展。
- 当前激活栏标识清楚；公共筛选/视图控件按激活栏状态显示并只作用于该栏。激活栏改变时，公共控件显示新栏当前设置。
- 在公共视图控制区的网格/列表按钮旁增加分栏按钮；弹出单栏、双栏、四栏选项，显示当前布局并可切换。
- 2026-10-19 用户追加局部调整：将顶部布局入口收敛为单个布局图标按钮；下拉菜单中保留单栏/双栏/四栏和多栏时的活动栏选择。移除工具栏上单独铺开的数字活动栏按钮，不移除活动栏功能。Gallery 的“显示子文件夹”图标改为 ToggleRight 切换图标，保留原有开关行为。
- 新按钮沿用现有图标按钮的尺寸、颜色、悬停/焦点/禁用状态、菜单样式和本地化提示，不改造现有按钮或其他界面外观。
- 各栏独立地址导航位于公共操作带的下一行，并与该栏文件网格在同一栏容器内。
- Everything 配置移入设置界面；搜索旁不显示 Everything 配置项。其余常用搜索功能留在右侧搜索/功能区域。
- 栏目彼此独立：地址历史、当前地址、媒体类型、标签/扩展/日期/评分筛选、排序/分组、网格/列表、缩略图大小、选择及滚动状态各自保存。公共操作栏切换目标时加载激活栏对应设置。
- 两栏左右排列；四栏为 2×2。各栏分隔线清楚；各栏地址导航与文件视图主体保持在同一栏目容器内。
- 公共操作以激活栏当前文件/选择为目标。全局侧栏导航可切换当前活动栏；右侧检查器显示活动栏上下文。
- 栏目保持可用的最小宽高；窗口空间不足时主体可滚动，不得让栏内关键导航/筛选控件被覆盖。

## 程序工作区

- 工作区是启动布局定义，不是媒体库、索引库或数据集。
- 一个工作区定义两栏或四栏以及每栏的地址、视图模式、排序/分组、筛选值和缩略图大小；每个定义有独立名称和稳定 ID。
- 支持保存当前布局为新工作区、覆盖保存、重命名、删除、切换默认启动工作区；启动时恢复默认工作区。
- 工作区清单用版本化 JSON：`%LOCALAPPDATA%\\PhoTag\\workspaces\\workspaces.json`。整份小型配置原子替换；旧版本通过 serde 默认值迁移。媒体查询仍走 Gallery 与共享数据库，不把媒体数据写进清单。
- 栏目运行时浏览状态属于 Gallery；工作区只保存可启动配置。用户切换工作区时，各栏目从定义重新构造并加载真实目录内容。

## 视觉与状态

- 沿用 `docs/ui-theme.md` 的工作台深蓝主题、字体、间距、组件和图标。
- 正常、活动栏、选中媒体、悬停/键盘焦点、空目录、筛选无结果、路径无效、保存失败、小窗口及长地址都要有可识别状态。
- 布局下拉菜单须显示当前布局及活动栏选中项；菜单关闭后当前栏公共操作路由保持一致。图标按钮需保留本地化 tooltip 与 accessibility label。
- 本轮图标/位置修正清单：公共视图区按「网格、列表、布局下拉、子文件夹开关、缩放」单行排列，布局入口紧邻列表而非置于缩放之后。复用公共 ghost 图标按钮，普通入口高度 30、图标 16，布局按钮为箭头留足横向空间；单栏用方框、双栏用左右分栏、四栏用 2×2 图标。子文件夹关闭用 ToggleLeft、开启用 ToggleRight，选中色跟随主题。保持下拉所有选项、当前布局/活动栏勾选和各栏操作目标。
- 用户追加开启态颜色：子文件夹开启后使用主题 primary 按钮的实色强调色底框和对比图标，鼠标移开仍保持；关闭时恢复普通 ghost 图标。沿用相同尺寸、圆角、位置和本地化提示，hover/pressed/focus 由原生按钮负责。
- 地址导航留在各自栏目并位于操作带下方；筛选/视图操作位于操作带左区，搜索/通用功能位于右区，两区视觉分开。
- 最新标注图规定筛选/排序/分组操作带位于地址行上方；概念图展示此层级。Everything 配置仅在设置界面提供，不回到工具栏。
