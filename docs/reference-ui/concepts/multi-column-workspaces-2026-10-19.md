# 多栏主工作区与程序工作区清单（2026-10-19）

活动参考：用户提供的 `codex-clipboard-b18b0b30-9403-4909-97ee-8e637eabea69.png`。
红框中的整个主浏览区域为一个可复用栏目单元；两栏或四栏布局由多个完整单元组成。

## 栏目结构

- 全局左侧栏和右侧检查器保留各一份，不进入分栏。
- 每栏顶部只保留自己的地址导航（后退、前进、上级、面包屑/地址输入）；其下为该栏独立的文件视图内容区域。
- 搜索及搜索范围/位置、筛选、排序、分组、网格/列表、子文件夹显示和缩放等视图操作全部放在主窗共享操作栏，不放入分栏。
- 公共操作栏只操作当前激活栏。激活栏改变时，公共控件显示该栏当前设置；调整后只更新该栏状态。
- 栏目彼此独立：地址历史、当前地址、媒体类型、标签/扩展/日期/评分筛选、排序/分组、网格/列表、缩略图大小、选择及滚动状态各自保存。公共操作栏切换目标时加载激活栏对应设置。
- 两栏左右排列；四栏为 2×2。各栏分隔线清楚；各栏地址导航与文件视图主体保持在同一栏目容器内。
- 公共操作以激活栏当前文件/选择为目标。全局侧栏导航可切换当前活动栏；右侧检查器显示活动栏上下文。
- 栏目保持可用的最小宽高；窗口空间不足时主体可滚动，不得让栏内关键导航/筛选控件被覆盖。

## 程序工作区

- 工作区是启动布局定义，不是媒体库、索引库或数据集。
- 一个工作区定义两栏或四栏以及每栏的地址、视图模式、排序/分组、筛选值和缩略图大小；每个定义有独立名称和稳定 ID。
- 支持保存当前布局为新工作区、覆盖保存、重命名、删除、切换默认启动工作区；启动时恢复默认工作区。
- 工作区清单用版本化 JSON：`%LOCALAPPDATA%\\PhoTag\\workspaces\\workspaces.json`。整份小型配置原子替换；旧版本通过 serde 默认值迁移。媒体查询仍走 Gallery 与共享数据库，不把媒体数据写进清单。
- 栏目运行时浏览状态属于 Gallery；工作区只保存可启动配置。用户切换工作区时，各栏目从定义重新构造并加载真实目录内容。

## 视觉与状态

- 沿用 `docs/ui-theme.md` 的工作台深蓝主题、字体、间距、组件和图标。
- 正常、活动栏、选中媒体、悬停/键盘焦点、空目录、筛选无结果、路径无效、保存失败、小窗口及长地址都要有可识别状态。
- 地址导航留在各自栏目；搜索、筛选、排序、分组和视图切换位于主窗公共操作栏。
- 参考图的文件视图主体按栏目独立显示；红框地址栏拆为各栏地址导航，筛选/视图操作提升为公共操作栏。概念图不替代这张用户参考，也不要求逐像素复制。

## 当前实现约束与验收清单

- 当前 Gallery factory 明确缓存唯一 `GalleryView` 实体，且 UI Bridge 将其三个区域贡献视图拆分注册。多栏不能只复制 view contribution：那会重复绘制同一实体并共享筛选/导航状态。
- 实现须提供可独立实例化的栏目 Gallery 状态，并将活动栏与全局导航/检查器明确关联；筛选、导航和动作不能经单例 UI request 互相覆盖。
- 栏目数、每栏筛选/地址、排序及模式在切换/重启后恢复；两栏/四栏布局均需真实渲染。
- 视觉验收须使用同进程 PhoTag MCP 截图，检查默认窗、小窗、长地址、各栏切换与独立筛选；目前均未验证。
