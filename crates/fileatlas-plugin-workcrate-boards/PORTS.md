# WorkCrate Boards ports

Cordis plugin `fileatlas.workcrate-boards` publishes service `fileatlas/workcrate-boards`; requires Projects service. Plugin startup publishes a client service and does not start VectorCraft until explicit `connect()`. Existing/user-owned native processes are never terminated by plugin cleanup.

`VectorCraftConfig { executable:String, port:u16 }` is read/written atomically at feature root/vectorcraft.json with backup; default port 17979; FILEATLAS_VECTORCRAFT_EXE fills an unset executable. No developer executable path is embedded. `connect()` probes exact live command IDs and returns catalogue diagnostics; configured executable is started with --control only when connection unavailable. Official GUI intentionally remains visible.

`document_path`, `attach_document`, `board_catalog`, `load_board`, `board`, `boards_for_project` expose native projects/artboards. Stable board identity is project UUID + persisted association UUID + native numeric artboard ID, current index is resolved from document.json each transaction. Existing dimensions are retained. Missing native link/import diagnostics remain blocked across client connections until explicit successful revalidation. Every explicit association rotates its UUID, including the same path. Dirty different documents are never overwritten.

`create_page`, `update_info`, `place_reference`, `place_file`, `save_project` mutate the official native document. First create uses file.new with one A3 landscape artboard; later creates use artboard.new. Material header values are native text with versioned fileatlas.workcrate notes and board IDs; direct external text edits are read back. Header groups include native background and human labels/values, no control flags or duplicate design JSON. Edits are undo grouped, with cancellation on known failure. Isolation mode is refused. Per-service serialized operations check active native path before mutation requests; external changes after a check remain an unavoidable control protocol race.

`render_preview(id,max_width)` uses official ui.render and cache identity includes native path/mtime/length/revision/id/size. `open_editor` uses native artboard navigation and ui.focus. Worker callers must keep all service IO off the GPUI render thread.

`export_native` is the public official export boundary for Export service; uses native artboard indices and supports one-document PDF selection. Fresh temporary native output is verified after background completion then atomically persisted. Returned native JSON retains warnings. Remote failure, mismatched IDs, malformed/oversized responses, IO and uncertain outcomes return BoardsError; mutations are never retried. Uncertain transport/protocol failures poison and shut down the client before any subsequent request can be written.

Limits: TCP loopback only, connect2s/read65s/write10s, replies32MiB, requests4MiB, bounded model traversal/text/extra fields. Header edits on boards narrower than200pt or shorter than100pt are refused. PDF across independent native documents is refused; no unofficial PDF merger exists. No source renderer/editor dependencies or legacy migration. Inspect native errors and WorkCrateExport progress for failures. No new events/framework infrastructure.
