# Shell composition ports / Shell 对接

`photag-shell` is the host composition root. It publishes `UiBridgeService`, starts Cordis plugins in dependency order, mounts GPUI view factories into host regions, and dispatches command IDs as Cordis events.

The shell restores `SessionState.sidebar_width` when it is between 160 and 500 pixels (otherwise 288 px) and saves the width when the sidebar divider drag ends. The updater is started before Settings. When Settings confirms an update it persists the current session snapshot, queues the staged path, and quits GPUI; after the application loop returns, the shell installs and relaunches the staged build before disposing the updater service. This update shutdown path still needs interactive Windows validation.

## Current runtime dependency order

Database → FileOperations → DragDrop → Gallery; Database → Preview → Gallery; Database → MediaPlayback → Gallery; Database → Thumbnails → Indexing → Watcher; Navigation depends on Database/Indexing and optionally Watcher; Settings reads Updater and Session and optionally reads Navigation; Tagging depends on Database; History starts after Database, FileOperations, and Tagging. Session and Updater start before Settings; AI starts after Settings when Gallery, MCP, all plugins, or the explicit `ai` development plugin is enabled. Shell starts Gallery after all required providers and the optional Settings/Tagging/History providers. The AI service is registered in Cordis, but Preview does not yet consume it. In `--mcp` mode it also starts all required feature providers, publishes the Shell-owned `CaptureWindowHandle`, and starts `photag.mcp` after Gallery, Navigation, Tagging, Preview, MediaPlayback, and FileOperations. After GPUI exits, Shell consumes any queued updater install before disposing Updater. On shutdown it stops MCP before Gallery and its providers, then stops Navigation before Watcher, Indexing, and Thumbnails. Preserve service availability before dependent plugin startup and stop consumers before providers. Gallery opens images in Preview, routes videos to MediaPlayback, calls DragDrop from card drag gestures, and optionally consumes Settings, Tagging, and History services.

## Boundaries

The shell must not absorb scanning, SQL, filtering, tagging, or file operations. It publishes the actual GPUI HWND through `photag-plugin-mcp::CaptureWindowHandle`; the MCP adapter captures only this PhoTag window on Windows. Stop plugin fibers before dropping shared runtime resources so Cordis cleanup can remove published services and UI contributions. Current shell and view host remain partial; see `docs/source-feature-audit.md` for unmigrated UI and behavior.
